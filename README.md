# 🏗 Architecture

CompIQ is designed as a lightweight production-style analytics platform focused on scalable full-stack engineering patterns.

The platform uses:
- Prisma for structured database querying
- PostgreSQL for compensation datasets
- Dynamic API routes for analytics
- Server-side rendering for performance
- Modular reusable component architecture

---

# 📌 Core Features

## 💰 Salary Intelligence System

Users can filter salaries by:
- company
- role
- level
- location

---

## 🏢 Company Intelligence Dashboard

Each company page includes:
- average compensation
- highest compensation
- total records
- role distribution charts
- AI-generated insights

## 🤖 AI Insights Engine

A deterministic analytics engine generates intelligent compensation commentary using compensation distributions and role patterns.
